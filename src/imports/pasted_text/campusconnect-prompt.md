## Recommended Tech Stack (Production-Ready)

* **Frontend:** Next.js + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion
* **Backend:** Python (Flask or FastAPI)
* **Database:** PostgreSQL (or MySQL)
* **Authentication:** JWT + OAuth (Google/LinkedIn)
* **Charts:** Recharts
* **Icons:** Lucide Icons
* **Storage:** Cloudinary or Supabase Storage
* **Deployment:** Vercel (Frontend) + Render/Railway (Backend)

This feature set turns your project from a basic placement portal into a comprehensive **AI-powered career intelligence and academia–industry collaboration platform**, making it much more compelling for SIH judges while remaining feasible to prototype.
